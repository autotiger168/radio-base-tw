# 📻 台灣電波地圖 Radio Base TW

收音機迷的基地台：台灣電台地圖、三種機身的復古收音機、MP3 錄音、全球短波「台灣可收」頻率表、
DX 收聽日誌、QSL 卡收藏牆、收音機鬧鐘。

> **第一次部署請看 👉 [部署教學.md](部署教學.md)**（step by step，約 40～60 分鐘）

---

## 功能一覽

| 分頁 | 功能 |
|---|---|
| **收音機**（常駐） | 三種機身：1950s 真空管、80s 短波機、現代科技・FM／AM／SW 三波段・拖曳旋鈕調台（含調台雜音、機械段落聲）・VU 表與頻譜・預設台 1–6（長按儲存）・REC 錄 MP3・SLEEP 睡眠定時 |
| **電台地圖** | 台灣電台標在地圖上・依波段／地區／縣市／類型篩選・資訊卡附官網與社群連結・自動配對線上串流 |
| **短波世界** | 依季節（A／B 季）與時間列出台灣可收的短波節目・★0–5 可收指數・時間 × 波段熱力圖・發射站大圓航線地圖・線上收聽・KiwiSDR 接收機・NOAA 傳播條件・顯示你的 DX 紀錄 |
| **DX 日誌** | SINPO 收聽紀錄・統計（電台數、發射地、最遠距離）・匯出／匯入 CSV・QSL 卡收藏牆（正反面照片）・完整備份與還原 |
| **錄音・鬧鐘** | 收音機鬧鐘（淡入、貪睡）・預約定時錄音・螢幕常亮・錄音室（試聽、改名、下載 MP3） |
| **廣播史・日本** | 台灣廣播史時間軸（1925 至今）・日本電台角落（線上收聽、日語短波、學日文素材） |

## 試算表欄位（「台灣電台」分頁）

| 欄位 | 說明 | 範例 |
|---|---|---|
| 編號 | 唯一編號，不要重複 | 41 |
| 台名 | 顯示在收音機上的名稱 | 大苗栗廣播電台 |
| 聯播網 | 同聯播網的不同頻率填一樣 | 中廣流行網 |
| 波段 | `FM` 或 `AM` | FM |
| 頻率 | FM 填 MHz、AM 填 kHz | 98.3／1089 |
| 地區 | 北部／中部／南部／東部／離島 | 北部 |
| 縣市 | | 苗栗縣 |
| 緯度、經度 | Google 地圖對地點按右鍵複製 | 24.565, 120.82 |
| 類型 | 自由填寫，會變成篩選選項 | 古典音樂 |
| 串流網址 | 空白時自動配對 | https://…/stream |
| 官網、Facebook、Instagram、Threads、YouTube | 空白時顯示「🔍 搜尋」按鈕 | |
| 預設台 | 1～6，對應收音機按鍵 | 1 |
| 已核對 | 確認過填 `Y` | Y |
| 備註 | 顯示在資訊卡 | 1995 年開播 |

「短波電台」分頁：**比對關鍵字**會拿去比對排程裡的英文台名（`NHK` 對到 NHK World Radio Japan），
對到後顯示中文名、官網，並用「串流搜尋名」自動找線上收聽。

## 重要說明

- **資料存在哪裡**：錄音、DX 日誌、QSL 卡、鬧鐘、預設台都存在「這台裝置的瀏覽器」裡，請定期在 DX 日誌分頁「匯出完整備份」。
- **鬧鐘與預約錄音**：網頁必須開著才會動作；iPhone 請停在網頁上並開啟「保持螢幕常亮」。
- **台灣可收指數**：依時段、頻段、距離、目標區估算的參考值，不是電離層預報。EiBi 排程沒有發射功率與天線方位，發射地以該國主要短波站估算。
- **錄音**：僅供個人收聽保存，請勿再散布。
- **電台資料**：第一版 40 筆，標示「待核對」的請實際確認後在試算表填 `Y`。台灣持照電台約 170 家，可陸續補進試算表。
