# 📻 台灣電波地圖 Radio Base TW

收音機迷的基地台：台灣＋大陸＋日本電台地圖（1,675 台）、16 款機身＋自訂照片的復古收音機、MP3 錄音、
全球短波「台灣可收」頻率表、DX 收聽日誌、QSL 卡收藏牆、收音機鬧鐘。

- 網站：https://autotiger168.github.io/radio-base-tw/
- 程式碼：https://github.com/autotiger168/radio-base-tw
- 串流中繼：https://radio-proxy.jarcle-huang.workers.dev

> **第一次部署請看 👉 [部署教學.md](部署教學.md)**（step by step，約 40～60 分鐘）

## 機身一覽（17 款）

收音機下方「機身」選單切換，◀ ▶ 逐款切換。每款的轉台雜音、VU 表（指針／LED）、頻譜動畫都不同。

| 分組 | 機身 |
|---|---|
| 經典 | 1950s 真空管、80s 短波機、現代科技 |
| 復古 | 昭和電晶體機、台灣懷舊客廳機、Art Deco 教堂型、80s 隨身聽 |
| 專業 | 軍用通訊機、專業通訊接收機、CRT 復古電腦 |
| 風格 | 蒸汽龐克、和風漆器、極簡北歐 |
| 棒球 | 猛虎綠黃、電光藍、藍盾護甲（原創設計，只取配色氛圍，不含任何球隊標誌） |
| 自訂 | 我的照片：按「🖼 換照片」選任何圖片當機身，只存在自己的瀏覽器 |

**新增一款機身：** ① 在 `js/radio-ui.js` 開頭的 `SKINS` 加一行（id、名稱、分組、音效、VU 樣式）
② 在 `css/skins.css` 加 `.radio[data-skin="新id"] { … }` 樣式（複製一款現有的來改顏色最快）。

| 串流網址 | 空白時自動配對 | https://…/stream |

## 日本電台

- **綠點（25 台）**：2026-10-28 從台灣網路逐台試播過，可直接收聽：NHK WORLD-JAPAN、AFN 美軍廣播 5 台、FM世田谷、湘南ビーチFM、FMかほく、FMわぃわぃ、網路電台、J-POP、古典音樂、東大森林現場收音。
- **灰色（199 台）**：NHK 第1／第2／FM（8 個地區）、民營台 38 台（radiko）、JCBA 社區 FM 144 台。這些平台依 IP 判斷所在地，只開放日本境內收聽，台灣實測無法播放，所以只列頻率與位置，不放上收音機刻度盤。
- 試算表「地區」填 `日本`、「串流網址」空白的台，網站會自動當成日本境內限定（灰色）。日後若找到可在台灣播放的串流，填進「串流網址」就會變成可收聽。

## 重要說明

- **資料存在哪裡**：錄音、DX 日誌、QSL 卡、鬧鐘、預設台都存在「這台裝置的瀏覽器」裡，請定期在 DX 日誌分頁「匯出完整備份」。
- **鬧鐘與預約錄音**：網頁必須開著才會動作；iPhone 請停在網頁上並開啟「保持螢幕常亮」。
- **台灣可收指數**：依時段、頻段、距離、目標區估算的參考值，不是電離層預報。EiBi 排程沒有發射功率與天線方位，發射地以該國主要短波站估算。
- **錄音**：僅供個人收聽保存，請勿再散布。
- **電台資料**：台灣電台來自 NCC 開放資料（政府資料開放平台 6445 FM、6446 AM），大陸電台來自蜻蜓 FM 與央廣。標示「待核對」的請確認後在試算表填 `Y`。
- **只有 IP 位址的串流**（例如 `http://123.45.67.89:8000/`）Cloudflare 中繼抓不到，換成有網域名稱的網址才能播。
- **短波季別**：EiBi 尚未發布新一季時，網頁自動使用最近一季的排程。

## 備存與還原

- **網站程式**：GitHub 上的版本就是正本；本資料夾是 2026-10-26 的完整備份。
- **`js/config.js` 注意**：備份裡的試算表網址是空白（GitHub 上那份才有你的真實網址）。
  還原時**不要用這份蓋掉 GitHub 上的 config.js**，或蓋掉後重新貼上兩個試算表「發佈到網路」的 CSV 網址
  （台灣電台 gid=0、短波電台 gid=515081126），中繼網址已填好。
- **`data/sw/`**：短波排程由 GitHub Actions 每週自動產生，備份裡沒有；還原後到 Actions 手動執行一次「更新短波排程」即可。
- **試算表**：Google 試算表本身請另外用「檔案 → 下載 → Microsoft Excel」備份。
- **瀏覽器裡的資料**（錄音、DX 日誌、QSL、鬧鐘、預設台）：在 DX 日誌分頁「匯出完整備份」。
